# Changelog

All notable changes to Grafite are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0]

### Added

- First release: the Graphite look (Grafite in Portuguese), 27 named colors on top of
  Atlas's dark look, declared through `atlas.themes` with plugin SDK version 24.
- Every text color is at least 4.5:1 (WCAG AA) on the four text grounds.
- A square icon for the Marketplace, `grafite/icon.png` (256x256), drawn in the theme's own colors
  from `grafite/icon.svg`.
- Screenshots at 1440x900 (rendered at 2x): a working conversation with tool calls and a code
  diff, the same scene in the default dark look, the four states, Settings with the look chosen,
  and the palette.
